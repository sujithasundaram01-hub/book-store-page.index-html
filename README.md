# 📚 XYZ Bookstore

A simple bookstore webpage built as part of my **freeCodeCamp HTML learning journey**.

## 🌐 About the Project

This project is a basic bookstore page that displays books with their titles, descriptions, and purchase buttons.

The project helped me practice using HTML elements such as:

- Headings
- Paragraphs
- `<div>` elements
- Classes
- IDs
- Buttons

## 🛠️ Technologies Used

- HTML5

## 📖 What I Learned

Through this project, I learned how to:

- Structure a webpage using HTML
- Use `<div>` elements to organize content
- Add and use classes
- Add unique IDs to elements
- Create buttons using the `<button>` element
- Organize webpage sections using proper HTML structure
